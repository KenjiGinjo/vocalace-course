听完一段，说不出卡在哪个词，下次遇到还是过。泛听可以很长、听一两遍就换。精听要短，听完留下一行记录。每周五段就够。同一段下周还可以再听，不必每次都换新的。

一段多长，见 [4.3.1](/4-listening/4-3/pick/)。四步怎么走，见 [4.3.2](/4-listening/4-3/flow/)。这课只练记下来。

这课目标：五段里至少先完成一段，卡点写成一个词或短语，并标上原因。

## 口型

这课不练嘴。一段走完 [四步](/4-listening/4-3/flow/) 之后，用两分钟填一行。

| | 泛听 | 精听 |
|--|------|------|
| 目的 | 维持输入 | 弄清某一处为什么没听见 |
| 长度 | 可以很长 | 大约 15 到 30 秒。再长就截开 |
| 听完 | 可以不记 | 写下卡点词和原因 |

说不出「卡在哪个词、是哪一种」，这次就是泛听。

有逐字稿更好核对。稿留到四步里的「对稿」，不要一开始就看。

## 对比词

卡点只标一种。例子都是前面课里听过的。

| 原因 | 听的时候 | 去哪一课 |
|------|----------|----------|
| 连读 | *pick it up* 像一个生词 | [4.2.2](/4-listening/4-2/link/) |
| 弱读 | *of*、*but* 轻得像没有 | [4.1.2](/4-listening/4-1/function/) |
| 闪音 | water [🔊](/audio/words/water.mp3) 被听成另一个词 | [4.2.1](/4-listening/4-2/flap/) |
| 音素 | 某个元音或辅音对不上 | [1.1](/1-phonetics/1-1/i-vs-ih/) 起的对比课 |
| 缩略 | gonna [🔊](/audio/words/gonna.mp3) 听成生词 | [4.1.1](/4-listening/4-1/reduced/) |

## 放进句子

听完用这两句向自己说。没有整句录音。空的地方填你这次的材料。

> I found five clips this week, about twenty seconds each.  
> /aɪ faʊnd faɪv klɪps ðɪs wiːk əˈbaʊt ˈtwɛnti ˈsɛkəndz iːtʃ/  
> 这周我留了五段，每段大约二十秒。

> I got stuck on "gonna". It was a reduction.  
> /aɪ ˈɡɑːt stʌk ɑːn ˈɡʌnə ɪt wəz ə rɪˈdʌkʃən/  
> 我卡在 gonna，那是缩略。

第二句里的词换成你自己的卡点。gonna [🔊](/audio/words/gonna.mp3) 只是例子。

## 常见错误

**1. 选了材料但没听，也算一次**  
一次就听大约 15 到 30 秒。时间不够就再截短，不要整段跳过。

**2. 卡点写成「那一句没听清」**  
拖到那一秒，写成 *of* 还是 *for* 这种具体的词。写不出词，就还没走到对稿。

**3. 表填了，原因空着**  
当场标连读、弱读、闪音、音素或缩略。同一种再出现，在那一行添一笔。下一周先练出现更多的那一种。

## 练习

### A｜先填一行（约 8 分钟）

找一段有稿的材料，截大约 15 到 30 秒。按四步走完，填表的第 1 行。卡点必须是词或短语。

| # | 日期 | 材料 | 秒数 | 卡点词 | 原因 | 回去练了吗 |
|---|------|------|------|--------|------|------------|
| 1 | | | | | 连读 / 弱读 / 闪音 / 音素 / 缩略 | |
| 2 | | | | | | |
| 3 | | | | | | |
| 4 | | | | | | |
| 5 | | | | | | |

过关：第 1 行的卡点是一个词或短语，原因五选一。

### B｜说出来（约 3 分钟）

用英文说这句，录音回听。空格换成你的内容：

> Today I listened to a clip. It was about twenty seconds. I got stuck on "___". It was ___ .

听回放里有没有那个词，以及五种原因里的哪一种。

### C｜迁移（选做）

一周五行走完，看哪一种原因出现更多。弱读多，先回 [4.1.2](/4-listening/4-1/function/)。闪音多，先回 [4.2.1](/4-listening/4-2/flap/)。把下周要练的那一种写在表下面。

## 自检

**1. 四步里，盲听时该怎么做？**

A. 打开文稿边看边听  
B. 只听，听不清的地方标「？」，先不查稿  
C. 一开始就跟读

答案：**B**。先看稿，卡点会被眼睛补上。

**2. 开口**

> I got stuck on the word "___". It was ___ .

卡点要是具体的词。说「有一句没听清」不算过。

**3. 是非**

「我填完卡点就关掉，没有标原因。」

如果是，下次先标五种里的一种，再关稿。如果不是，周末看哪一种出现更多，下周先练那一种。
