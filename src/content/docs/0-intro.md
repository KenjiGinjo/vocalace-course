学什么、不学什么：

- **学**：美式发音、语流、听力缩略、中英思维差（冠词/单复数）、美式日常搭配
- **不学**：完整语法体系、英式 48 音标体系、背单词大赛

### 单课原则

- 一次只练一个音素或一种语流现象
- 流程：示范 → 口型要点 → 对比词 → 放进句子 → 录音回听

### 自检标准

- 能听出自己错在哪个音素
- 对比词能分清（如 ship / sheep）
- 放进句子后仍站得住，不只在单词表里准

音标与词库一致：通用美语（General American）。目标是**别人听得懂、自己听得清**，不承诺「纯正口音」。
