打电话想预约，嘴里出来的是 *I want to book*。对方报了两三个时段，你只会 *OK*，挂断以后不确定约的是哪一个。诊所和理发是同一套：说来意，选时间，报名字，把约好的时间再说一遍。

*I'd* 是 /aɪd/，*d* 要在。*to* 不强调时是 /tə/。钟点见 [7.4.1](/7-expressions/7-4/date/)。名字怎么拼见 [8.3.2](/8-scenarios/8-3/message/)。电话开头如果要自报名字，见 [8.3.1](/8-scenarios/8-3/open/)。

没有整句录音。like [🔊](/audio/words/like.mp3)、have [🔊](/audio/words/have.mp3)、name [🔊](/audio/words/name.mp3)、see [🔊](/audio/words/see.mp3)、great [🔊](/audio/words/great.mp3) 只对单词。

这课目标：开口是 *I'd like to make an appointment* 或 *I'd like to book a haircut*。有空说 *That works for me.* 挂之前重复对方报的时间。

## 口型

| 到哪一步 | 你说 | 不要说成 |
|----------|------|----------|
| 说来意 | I'd like to make an appointment. | I want to book. / 漏掉 an |
| 点明找谁、做什么 | with Dr. Chen / book a haircut | — |
| 问有没有空 | Do you have anything this Friday? | in this Friday、on this Friday |
| 这个时间可以 | That works for me. | 只说 OK |
| 想早一点或晚一点 | Actually, do you have anything a little earlier / later? | 沉默 |
| 报名字 | My name is …. | 不说是名还是姓 |
| 收尾 | Great, so that's + 对方刚说的时间. I'll see you then. | 只说 OK, bye |

*this Friday*、*next Monday morning*、*sometime next week* 前面不加 *on* 或 *in*。

对方问 *new or existing patient*：你来过就说 *I'm an existing patient.* 头一回说 *I'm a new patient.*

## 对比词

| 说法 | 音 |
|------|----|
| I'd like to | /aɪd laɪk tə/ |
| an appointment | /ən əˈpɔɪntmənt/ |
| this Friday | /ðɪs ˈfraɪdeɪ/ |
| That works for me. | /ðæt wɝːks fɚ mi/ |
| I'll see you then. | /aɪl si jə ðɛn/ |

*like* 是 /laɪk/。like [🔊](/audio/words/like.mp3)。*appointment* 重音在 *point*。*an* 要在，因为后面是元音。

*have* 单独念是 /hæv/。have [🔊](/audio/words/have.mp3)。问句里可以更轻。*for* 是 /fɚ/。*you* 快了是 /jə/。see [🔊](/audio/words/see.mp3) /siː/。

*Friday the 7th at 3:15* 是对方用来确认的说法：周五、7 号、三点十五。你把这串再说一遍。*7th* 是 /ˈsɛvənθ/。自己报钟点时带上 *AM* 或 *PM*。

## 放进句子

**句 1：**

> Hi, I'd **like** to make an ap**point**ment with Dr. Chen, please.  
> /aɪd laɪk tə meɪk ən əˈpɔɪntmənt wɪð ˈdɑːktɚ tʃɛn/  
> 你好，我想预约陈医生。

*Dr.* 是 /ˈdɑːktɚ/。重音在 *like* 和 *point*。

理发把这一句换成：*I'd like to book a haircut, please.* /ˈhɛrkʌt/

**句 2：**

> Do you have anything this **Friday** afternoon? **That** works for **me**.  
> /duː ju hæv ˈɛniθɪŋ ðɪs ˈfraɪdeɪ ˌæftɚˈnuːn ‖ ðæt wɝːks fɚ mi/  
> 这周五下午有空吗？这个时间可以。

对方说 *We have a 3:15 opening.* 你接 *That works for me.* 收尾：*Great, so that's Friday the 7th at 3:15. I'll see you then. Thanks.* great [🔊](/audio/words/great.mp3) /ɡreɪt/。

## 常见错误

**1. I want，或漏掉 an**  
整句是 *I'd like to make an appointment.* *an* 和 *appointment* 连着说，不要在 *make* 后面停住再找冠词。

**2. this Friday 前面加 in 或 on**  
日期词组直接接在 *anything* 后面。听到自己说出 *in*，只重录这一句。

**3. 挂之前不重复时间**  
对方报完，你用 *so that's* 把星期、日期、钟点再说一遍。对上了再道谢。

## 练习

### A｜跟读（约 4 分钟）

下面是你的台词。各说两遍，录第 1 句和最后一句。回听有没有 *I want*，*Friday* 前面有没有多余的介词。

对方可能问：*How can I help you?* / *New or existing?* / *We have a 3:15 opening. Does that work?*

- Hi, I'd like to make an appointment with Dr. Chen, please.
- I'm an existing patient. My name is Li Wei.
- Do you have anything this Friday afternoon?
- That works for me.
- Great, so that's Friday the 7th at 3:15. I'll see you then. Thanks.

名字要拼的话，用 [8.3.2](/8-scenarios/8-3/message/) 的 *as in*。name [🔊](/audio/words/name.mp3)。

过关：能指出自己漏了 *an*，还是没收尾。

### B｜开口（约 4 分钟）

你叫 Zhang Min，想约下周三上午理发。没有的话，下周四也可以。对方的话印在下面。你说这四句，录第 1 句和第 4 句。

1. 对方：*Thank you for calling. How can I help you?*  
   你：*Hi, I'd like to book a haircut, please.*  
2. 对方：*Wednesday at 10 or Thursday at 2?*  
   你：*Thursday at 2 works for me.*  
3. 对方：*Can I get your name?*  
   你：*My name is Zhang Min.*  
4. 对方报出时间。  
   你：*Great, so that's Thursday at 2. I'll see you then.*

*10* 说 *ten*。*2* 说 *two*。只改听出来的那一处。

### C｜迁移（选做）

换成眼科检查。两处用新词：*I'd like to make an appointment for an eye exam.* 其余仍是问时段、*That works for me*、重复时间。说四句。

## 自检

**1. 电话里说要预约，你用哪句？**

A. I want to make appointment.  
B. I'd like to make an appointment.  
C. I need booking.

答案：**B**。A 少了 *an*。C 不是这课的开口。

**2. 开口**

> I'd like to make an appointment. Do you have anything next Monday morning? That works for me.  
> /aɪd laɪk tə ‖ ˈnɛkst ˈmʌndeɪ ˈmɔːrnɪŋ ‖ ðæt wɝːks fɚ mi/

*I'd* 是 /aɪd/，不要展开成 *I would*。*for* 是 /fɚ/。*Monday* 前面没有 *on*。

**3. 是非**

你说了 *OK, bye* 就挂了，没有重复时间。

加上 *Great, so that's* 和对方刚说的时间，再说一遍。
