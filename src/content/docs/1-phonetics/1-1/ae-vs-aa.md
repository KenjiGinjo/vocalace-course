你大概从没觉得 *cat* 和 *cot* 不一样——中文里「啊」就是「啊」。但对美国人，这两个词差得很明显。*hat / hot、bad / bod、cap / cop* 混在一起，对方就得猜。

这课只做一件事：让嘴做出两个不同动作，把这两个音分家。

## 口型

### /æ/（cat, hat, bad）

| 要素 | 说明 |
|------|------|
| 舌位 | 舌体**前移**、舌面略抬；舌尖顶下齿背 |
| 唇形 | 嘴角**向两侧拉开**，像准备苦笑；纵向开度中等 |
| 下巴 | 稍微下沉，不是全力张开 |
| 感觉 | 嘴角有「被往两边扯」的紧绷感 |

不要直接上下张大、舌根下沉——那会变成 /ɑː/ 或中文「啊」。

### /ɑː/（cot, hot, father）

| 要素 | 说明 |
|------|------|
| 舌位 | 舌体**后缩**、舌面低平；舌尖离开下齿 |
| 唇形 | 嘴角**不横拉**；嘴**上下张大**，唇**不圆、不撅** |
| 下巴 | 明显下落，开口大于 /æ/ |
| 感觉 | 下颌自然掉开，喉咙开阔 |

美式 *hot / cot / father / stop* 全是不圆唇的 /ɑː/。英式 *hot* 常带圆唇（/ɒ/），美式不圆——对着镜子：嘴唇应是平展的。

### 两音对比

```
/æ/          /ɑː/
嘴角横拉     嘴上下张开
舌体前       舌体后
开度中       开度大
唇不圆（紧） 唇不圆（松）
```

## 放进句子

**句 1：**

> ***The **cat** is **not** on the **mat**.***  
> /ðə ˈkæt ɪz ˌnɑːt ɑːn ðə ˈmæt/  
> 那只猫不在垫子上。

同一句里 /æ/（cat, mat）和 /ɑː/（not）交替，练快速切换。

**句 2：**

> ***My **dad** got a **job** at the **lab**.***  
> /maɪ ˈdæd ˌɡɑːt ə ˈdʒɑːb æt ðə ˈlæb/  
> 我爸在实验室找到工作了。

dad / lab = /æ/；got / job = /ɑː/。

## 常见错误

| # | 表现 | 纠正 |
|---|------|------|
| 1 | /æ/ 时嘴直接上下张开（像医院「啊」） | 食指放两侧嘴角，确认嘴角**向外**压住手指 |
| 2 | /ɑː/ 时嘴唇往前撅（像英式 /ɒ/ 或「哦」） | 先抿成一条直线，再张开下巴；镜中有弧度就重做 |
| 3 | 两个音听感一样 | 先夸张慢动作：确认 /æ/ 嘴角比 /ɑː/ 更宽，再缩回正常语速 |

## 练习

### A｜跟读（约 5 分钟）

1. 听 cat [🔊](/audio/words/cat.mp3)–cot [🔊](/audio/words/cot.mp3)、hat [🔊](/audio/words/hat.mp3)–hot [🔊](/audio/words/hot.mp3)，先只听  
2. 跟读对比 ×5，每次停 1 秒照镜子  
3. 录六个词连续说一遍  
4. 回听：/æ/ 时嘴角是不是更宽？  
5. 语流句 ×3  

过关：能指出哪个词嘴角没拉开或嘴唇撅圆了，并再录一次有改变。

### B｜单词汇音（约 5 分钟）

bad [🔊](/audio/words/bad.mp3) / bod [🔊](/audio/words/bod.mp3)　　cap [🔊](/audio/words/cap.mp3) / cop [🔊](/audio/words/cop.mp3)

1. 听示范，跟读一遍  
2. **逐词录音** → 立刻回放 → 只改听出来的那一处  
3. 改完再录同一词，再换下一个  
4. 慢速（约 0.7×）确认口型 → 正常语速再录  

提示：/æ/ 组把镜中嘴角宽度当基准；/ɑː/ 组先把嘴唇按平再张开下颌。

### C｜迁移（选做，约 3 分钟）

标出 /æ/ 与 /ɑː/，朗读并录音：

> *"Can you grab a map? My car is parked past that black box."*

参考：/æ/ → can, grab, map, past, that, black；/ɑː/ → box。（car、parked 是 /ɑːr/，本课不计入）

## 自检

**1. 辨音**  
**hot** 是？　A. /hæt/　B. /hɑːt/  

答案：**B**。选错就先只听 cat–cot、hat–hot 各五遍，不跟读。

**2. 开口读**

> *"The cat is not on the mat."*

查：① cat / mat 嘴角横拉了吗；② not 嘴唇有没有撅圆。

**3. 是非**  
对着镜子发 *hot*：「我发 /ɑː/ 时嘴唇平展、没有往前撅。」  
应选「是」。若否：抿平嘴唇再张开下颌，直到镜中无收拢。
