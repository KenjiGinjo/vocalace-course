点咖啡说 *"I need a seat"*，服务员以为是 *"I need to sit"*？跟朋友说 *"nice beach"*，场面突然微妙？

区别往往不在「拖没拖长」，而在嘴角和舌头有没有**用力**。中文「衣」已经接近，但发 /iː/ 时嘴角常常没绷紧，两个音就混在一起。

这课目标：照镜子就能自检——嘴角绷了没有。

## 口型

### /iː/——绷紧 + 舌尖抵下齿

| 要点 | 动作 |
|------|------|
| 嘴角 | **向两侧用力拉开**，像龇牙笑，脸颊收紧 |
| 嘴唇 | 薄而展开，上下齿接近但不咬合 |
| 舌位 | **高且靠前**，舌尖轻抵下齿背，舌面向上颚弓起 |
| 时长 | 相对较长，紧张状态保持到音发完 |
| 易错 | 发成中文「衣」——嘴角不够紧、舌位偏低 |

### /ɪ/——放松 + 舌位略降

| 要点 | 动作 |
|------|------|
| 嘴角 | **不用力**，脸颊放松 |
| 嘴唇 | 稍微圆一点点（不是 /uː/ 那种圆） |
| 舌位 | 比 /iː/ **稍低、稍后**，舌尖不必用力顶下齿 |
| 时长 | 短而松 |
| 易错 | ① 加了嘴角用力 → 变成 /iː/；② 发成尖而靠前的短「一」——仍然太绷 |

**口诀：/iː/ 用力咧嘴笑，/ɪ/ 放松别绷脸。**

## 放进句子

**句 1（全是 /iː/）：**

> **"She** needs a **seat** near the **beach**."  
> /ʃiː niːdz ə siːt nɪɹ ðə biːtʃ/  
> 她需要一个靠近海滩的座位。

She / needs / seat / beach——全程嘴角保持紧张。

**句 2（全是 /ɪ/）：**

> "**This ship** is **big**."  
> /ðɪs ʃɪp ɪz bɪɡ/  
> 这艘船很大。

this / ship / is / big——全程放松，不要在任意一词绷紧。

## 常见错误

**1. 两个音都发成紧绷的 /iː/**  
sit 像 see，ship 像 sheep。  
纠正：发 /ɪ/ 前下巴微微下沉约 2 mm，强制嘴角不用力；镜子里脸颊应是软的。

**2. /iː/ 只拖长、嘴角没绷**  
变长了但含糊，没有清脆的 "ee"。  
纠正：食指放在嘴角外侧，发 /iː/ 时应感到手指被向外推。

**3. /ɪ/ 发成尖而靠前的短「一」**  
口音感重。  
纠正：先「半打哈欠」放松下颌和舌头，再从这个状态发音；舌尖别用力顶下齿。

## 练习

### A｜跟读（约 5 分钟）

1. 先完整听一遍例词，不跟读，只感受松紧  
2. 逐词跟读 ×5，**对着镜子看嘴角**  
3. 两句各跟读 ×3  
4. 录一整轮词组 + 两句  
5. 回听：找「嘴角有没有真的换」  

过关：能指出哪个词 /iː/ 没绷，或哪个词 /ɪ/ 绷了。

### B｜单词汇音（约 4 分钟）

1. see [🔊](/audio/words/see.mp3) vs sit [🔊](/audio/words/sit.mp3)  
2. sheep [🔊](/audio/words/sheep.mp3) vs ship [🔊](/audio/words/ship.mp3)  
3. seat [🔊](/audio/words/seat.mp3) vs sit [🔊](/audio/words/sit.mp3)  
4. beach [🔊](/audio/words/beach.mp3) vs bitch [🔊](/audio/words/bitch.mp3)  
5. tea [🔊](/audio/words/tea.mp3)，six [🔊](/audio/words/six.mp3)

流程：先录 /iː/ → 立刻回放 →「嘴角绷了吗？」→ 只改听出来的那一处 → 再录。镜子：/iː/ 嘴角明显外拉，/ɪ/ 几乎不动。先慢后正常语速。

### C｜迁移（选做，约 2 分钟）

先判断再读，镜子确认松紧：

| 词 | /iː/ 还是 /ɪ/？ |
|----|----------------|
| *field* | ? |
| *fill* | ? |
| *meal* | ? |

答案：field /fiːld/（绷）、fill /fɪl/（松）、meal /miːl/（绷）。

## 自检

**1. 辨音**  
听 seat 与 sit：哪个更「亮、锐」？那是 /iː/（seat）。听不出来就各听三遍再判。

**2. 开口读**（录音）

> *"She needs a seat near the beach."*

She / needs / seat / beach——每个词嘴角都绷了，还是只绷了第一个？

**3. 是非**  
「把 /iː/ 发得比 /ɪ/ 长就够了。」→ **否。**  
松紧在前，长短在后；只拖长、嘴角不绷，听感仍然不对。
